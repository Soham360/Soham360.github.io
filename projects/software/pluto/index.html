Web Application

Pluto — Empowering Students with Organization

Pluto is a holistic productivity tool designed to enhance student organization through bell schedule management, weather-based recommendations, task planning, and announcements.

Overview

Pluto is more than just a daily planner; it's a holistic tool designed to enhance student productivity and organization. From bell schedule management to weather forecasts, Pluto has it all.

Key Features

  • Bell Schedule Calculator: Efficient time management tool tailored for students.
  • Weather Integration: Real-time weather updates with clothing recommendations.
  • Task & Announcements: Planner and announcement board for seamless coordination.

Tech Stack

HTML · CSS · JavaScript · Amazon EC2 · Amazon Route 53 · Spring Boot · Java
