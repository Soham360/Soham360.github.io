Web Application

Lyntax — Hangman Game for CS Learning

An interactive learning tool designed to make studying computer science terms engaging and fun through gameplay.

Overview

Lyntax is more than just a game; it’s an interactive educational platform engineered to help students memorize and study computer science terminology. Built with Python’s Flask framework for the backend REST API and Vue.js for the dynamic frontend, it provides an intuitive, responsive user experience hosted on Amazon EC2.

Key Features

  • Dynamic Word Selection: Fetches computer science terms from an extensive database.
  • Progressive Reveal: Displays hidden word structures dynamically as correct guesses are entered.
  • Interactive Visuals: Real-time hangman graphics updating dynamically to mirror incorrect guesses.

Tech Stack

HTML · Flask · Python · Vue.js · CSS · JavaScript · Amazon EC2
