Web Application

Petite Pandas — Sports Stats Simplified

A comprehensive sports statistics organizer designed to streamline data management and analysis for enthusiasts and analysts.

Overview

Petite Pandas simplifies NBA data analysis by aggregating key metrics and providing accessible visualization tools.

Key Features

  • Detailed Statistics: Displays comprehensive performance metrics for any NBA team from the 2022–2023 season.
  • Dynamic Sorting: Allows custom sorting across key metrics including Points, Rebounds, Assists, and more.
  • Data Visualization: Visualizes statistical breakdowns through interactive pie charts and bar graphs.

Tech Stack

HTML · Flask · Python · CSS · JavaScript · Amazon EC2 · pandas · NumPy
