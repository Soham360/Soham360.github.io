Web Application

Cars — Sorting Cars Stats

Sorting car stats visually using different sorting algorithms.

Overview

The Cars project involved creating a visual demonstration of sorting algorithms applied to car statistics. It featured a grid layout containing 12 cars, each with unique stats. Using bubble sort, selection sort, merge sort, and insertion sort, users could observe how the cars dynamically rearranged themselves based on their stats when the sort button was pressed. Additionally, a table displayed the efficiency of each sorting method.

Key Features

  • Visual Sorting: Interactive visual representation of sorting algorithms applied directly to car statistics.
  • Algorithm Support: Demonstration of bubble sort, selection sort, merge sort, and insertion sort.
  • Dynamic Rearrangement: Cars dynamically move to their respective sorted positions upon execution.
  • Efficiency Comparison: Comparative performance table showcasing execution time and algorithm metrics.
