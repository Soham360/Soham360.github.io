Web Application

Cars — Sorting Cars Stats

A 12-car grid that reorders itself in real time depending on which sorting algorithm you pick.

Overview

Built to visualize sorting algorithms beyond Big-O notation, this tool places twelve cars in a grid with distinct stats and rearranges them live using bubble, selection, merge, or insertion sort. An adjacent table tracks runtime to demonstrate performance differences numerically.

Key Features

  • Visual Sorting: Watch each algorithm move the cars into place instead of just printing a sorted array.
  • Algorithm Support: Bubble sort, selection sort, merge sort, and insertion sort, swappable on the fly.
  • Dynamic Rearrangement: Cars animate into their new positions as the algorithm runs.
  • Efficiency Comparison: A side table logs execution time so you can compare algorithms directly.

Tech Stack

HTML · CSS · JavaScript · Amazon EC2 · Amazon Route 53 · Spring Boot · Java
