Web Application

Jobify — Bridging Students and Internship Opportunities

Internship management platform with separate student, employer, and admin views, alongside a support chatbot.

Overview

Jobify came out of watching how disorganized internship applications get once emails, spreadsheets, and file attachments start piling up. It gives students, employers, and admins their own view of the same pipeline, so applications, feedback, and file submissions stay in one place instead of scattered across inboxes.

Key Features

  • Role-Based Access: Students, employers, and admins each see a dashboard suited to what they actually need to do.
  • Direct Messaging: Built-in channels so students and employers can talk without leaving the platform.
  • AI Assistance: A chatbot answers common questions so students aren't waiting on email replies for basic stuff.
  • Application Tracking: Upload files and check application status without digging through email threads.

Tech Stack

HTML · CSS · JavaScript · Java · Spring Boot · Amazon EC2 · Amazon Route 53
