Jobify — Bridging Students and Internship Opportunities

Jobify is revolutionizing the internship search process by blending innovation with practicality. With features like role-based access and AI chatbots, it’s reshaping how students connect with employers.

Overview

Jobify serves as a comprehensive platform streamlining communication, file submissions, and application tracking between students and employers.

Key Features

  • Role-Based Access: Structured user hierarchy tailored for students, administrators, and employers.
  • Seamless Communication: Dedicated channels between key stakeholders for efficient collaboration.
  • AI Assistance: Integrated AI chatbot providing instant guidance and student support.
  • Application Tracking: Streamlined file submission and feedback mechanisms.

Tech Stack

HTML · CSS · JavaScript · Java · Spring Boot · Amazon EC2 · Amazon Route 53
