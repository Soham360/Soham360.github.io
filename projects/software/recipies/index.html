Web Application

ReciPies — Your Culinary Companion

A handy web application for discovering delicious recipes tailored to your dietary preferences.

Overview

ReciPies is an intuitive recipe discovery platform equipped with custom search filtering and a community review system, making it a must-have tool for home cooks and aspiring chefs.

Key Features

  • Customizable Search: Filter recipes based on personal dietary restrictions and preferences.
  • Review System: User-friendly interface for sharing culinary experiences and rating dishes.
  • Favorites: Convenient feature to bookmark and save favorite recipes for quick access.

Tech Stack

Python · Flask · HTML · CSS · JavaScript · Amazon EC2
